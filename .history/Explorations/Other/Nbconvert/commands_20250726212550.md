
### 📄 Export as PDF without code cells

Removes all code input cells and exports a clean, print-ready PDF document. Ideal for sharing results with non-technical stakeholders.

```bash
jupyter nbconvert main.ipynb --no-input --to pdf
```

---

### 🌐 Export as HTML without code cells or input prompts

Generates an HTML report with no code or execution prompts. Suitable for visual summaries and online publishing.

```bash
jupyter nbconvert main.ipynb --to html --no-input --no-prompt
```

### 🔄 Convert to plain Python script

Extracts the code into a `.py` script, ignoring markdown. Useful for debugging, version control, or automation.

```bash
jupyter nbconvert main.ipynb --to script
```

---

### 🧹 Clear all output cells and save clean notebook

Strips output from the notebook, useful before committing to Git or sharing raw notebooks.

```bash
jupyter nbconvert main.ipynb --clear-output --inplace
```

---

### 📦 Export Markdown (for static site generators or Jupyter Book)

Converts notebook to Markdown with embedded image outputs. Useful for blog posts or documentation pipelines.

```bash
jupyter nbconvert main.ipynb --to markdown
```
